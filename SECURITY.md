---

## Reporting a Vulnerability

We take the security of this project, asset encryption integrity, and the code seriously.

If you discover a security issue or vulnerability (such as a flaw in the asset encryption mechanism or potential memory leaks in native libraries):

1. **Please do NOT open a public issue.**
2. Send an email to the project maintainer at `kamaleshorbit@gmail.com` with:
   - A description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Any suggested mitigations.
3. You will receive an acknowledgment within 48 hours, followed by an assessment and patch plan.
